OmniVoice replaces CSM as the app's active engine. The Android package and existing
stable signing key are unchanged. Saved recordings remain available.

The APK contains no voice weights. Download OmniVoice inside the app after installing.
The complete verified download size is shown before downloading. The old CSM package
is removed only after all new files pass verification and the new package is installed.

- Dhivehi text generation, long-text sections, playback and WAV export.
- Optional offline voice cloning: import a clear 3–10 second PCM16/float WAV and
  enter the exact transcript. Select Saved reference voice before generating.
- Generation progress reports model steps, separate from audio duration.
- Cancelling preserves completed sections as a partial recording.
- All generation uses 32 diffusion steps. No Python or online speech service.

This is a test release. Numerical checks do not guarantee natural pronunciation.
Please test a short sentence first, then a paragraph, with airplane mode enabled.
Report audio duration, generation time, missing/repeated words and phone heating.
